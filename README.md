ドタバタ宝さがしは、ドット絵の遺跡で宝石を集め、30秒以内の脱出を目指すアクションです。宝石8個で出口が開き、カギと宝箱で追加得点。苔の遺跡・ひかり鉱山・月夜の古城の3マップ、方向ボタン／矢印／WASDとダッシュに対応します。スライム・コウモリ・予告付きのトゲを避けて光る階段へ。途中中断では挑戦回数を増やさず、端末内だけに記録します。ドット絵と14種類のSEはオリジナルです。

銀河防衛隊は、宇宙船を左右に操作し、4種類の宇宙人の3編隊と巨大母船を迎撃する約1分のシューティングです。自動連射、指のドラッグ・左右ボタン・矢印／A D、1出撃2発の敵弾消去ボム、3段階の武器強化と修理に対応します。母船は予告線からビーム・扇弾・交差弾を発射。中断では記録を増やさず、終了した出撃だけ端末内へ保存します。宇宙船・宇宙人・背景・効果音はオリジナルです。

ギリギリ風船は、風船かボタンを長押ししてふくらませ、破裂する前に離す約5〜10秒のミニゲームです。大きさ・薄さ・震え・空気音とゴムの音で危険を見極めます。近くで止めるほど高得点、割れると0点。結果から長押し1回で即リトライできます。風船ごとの時間は少し変わり、危険サインの圧力基準は共通です。Space・Enterでも操作でき、中断は挑戦回数に数えず、記録は端末内に保存します。

ボロ車ドリフトは、錆びた軽自動車を賞金で改造し、6つのコースで3台のライバルに挑むレースゲームです。自動アクセル、左右のハンドル、入口でタイミングを合わせるドリフト、直線のニトロに対応。エンジン・タイヤ・車体はそれぞれ3段階で、加速・グリップ・耐衝突性が変わり、錆、青い塗装、フェンダー、ウイングなど外観も変化します。進行・得点は端末内保存。中断したレースはガレージから再挑戦でき、獲得済みの資金や改造は保持します。

ことば横丁は、8枚のひらがな牌に1枚引き、異なる2文字・3文字・4文字の言葉を作る日本語パズルです。読む順にタップして置き、確定済みの言葉も手札へ戻して組み直せます。CPU対戦3段階と、18問のひとり練習、885語の検索できることば帳、1局3回のヒント、オリジナル効果音があります。認める言葉はことば帳の登録語に限定し、進行・得点は端末内だけに保存します。CPUは自分の手札と表の捨て牌だけを使って判断します。

## 開発

Node.js22以上。公開ビルドには追加パッケージ不要。

```sh
node scripts/build-site.mjs
node scripts/build-single.mjs
```

公開対象はdist/。単体HTML試遊版にはサーバーがなく、共通ランキングは利用できません。試遊版の記録を公開ランキングへ後から送ることはしません。

## ゲーム追加

AGENTS.mdとgames/EXAMPLE.jsを参照。catalog.js、i18n.js、games/<id>.jsを追加し、cleanupとcleanup.retranslateで後処理・進行を保つ翻訳に対応します。ゲームは選択時に遅延読み込みします。描画などの依存モジュールはcatalogのscripts配列で宣言し、ゲーム本体より先に読み込みます。

## 運用

Cloudflare Pages＋D1の無料枠を使用。共通ランキングの仕様・制限・個人情報の扱いはbackend/README.mdとprivacy.html、公開手順はDEPLOYMENT.md、試験結果はTEST-REPORT.mdに記載しています。効果音は端末内で合成し、外部の音素材・マイク権限を使いません。広告、解析タグ、課金は行いません。

2026年10月28日以降は、オーナーがゲームのアイデアを出し、Codexが開発・試験・公開から、動画付きX投稿とリプ欄のゲーム直リンクまで担当します。投稿先は「あそび横丁」@mtrdswg。新作の公開URLを検証してから投稿し、動画・返信・リンクの到達を確認して、投稿URLを報告します。具体的な運用はAGENTS.mdを参照。
